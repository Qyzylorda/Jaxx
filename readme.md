# Roadmap Planner - Модульное приложение для создания планов и дорожных карт

## Описание

Roadmap Planner - это веб-приложение для визуального планирования проектов, создания дорожных карт и схем. Приложение построено по модульному принципу, что позволяет легко добавлять новые функции или отключать существующие без нарушения работоспособности основной системы.

## Возможности

### Типы объектов
- 📌 **Заголовок** - для обозначения основных разделов
- 📋 **Тема** - для группировки связанных элементов
- ✅ **Задача** - для конкретных задач и действий
- 🚩 **Веха** - для ключевых точек проекта
- 📝 **Заметка** - для дополнительной информации

### Функции
- Добавление объектов на рабочую область
- Перетаскивание объектов (Drag & Drop)
- Создание соединений между объектами (двойной клик → клик)
- Редактирование свойств объектов (тип, текст, цвет, размер)
- Масштабирование рабочей области (колесо мыши)
- Экспорт проекта в JSON и PNG
- Импорт проектов из файлов
- Автосохранение в localStorage

## Модульная архитектура

### Ядро приложения (app.js)
- `RoadmapApp` - основной класс приложения
- `ModuleSystem` - система управления модулями

### Модули

#### 1. ObjectModule (обязательный)
**Файл:** `js/modules/object-module.js`

Базовый модуль для работы с объектами. Отключать нельзя!

Функции:
- Создание объектов разных типов
- Управление свойствами объектов
- Экспорт/импорт отдельных объектов

#### 2. DragDropModule (опциональный)
**Файл:** `js/modules/dragdrop-module.js`

Модуль перетаскивания объектов мышью.

Как отключить: Закомментировать строку подключения в `index.html`:
```html
<!-- <script src="js/modules/dragdrop-module.js"></script> -->
```

#### 3. ConnectionModule (опциональный)
**Файл:** `js/modules/connection-module.js`

Модуль создания соединений между объектами.

Использование: Двойной клик по первому объекту → клик по второму.

Как отключить: Закомментировать строку подключения в `index.html`:
```html
<!-- <script src="js/modules/connection-module.js"></script> -->
```

#### 4. ExportImportModule (опциональный)
**Файл:** `js/modules/export-import-module.js`

Модуль экспорта и импорта проектов.

Функции:
- Сохранение проекта в JSON
- Загрузка проекта из файла
- Экспорт в изображение (PNG)
- Автосохранение в localStorage

Как отключить: Закомментировать строку подключения в `index.html`:
```html
<!-- <script src="js/modules/export-import-module.js"></script> -->
```

#### 5. UIModule (опциональный)
**Файл:** `js/modules/ui-module.js`

Модуль пользовательского интерфейса.

Функции:
- Панель инструментов
- Панель добавления объектов
- Панель свойств объекта

Как отключить: Закомментировать строку подключения в `index.html`:
```html
<!-- <script src="js/modules/ui-module.js"></script> -->
```

**Важно:** При отключении UIModule управление будет возможно только через API в консоли разработчика.

#### 6. ModuleManagerModule (опциональный)
**Файл:** `js/modules/module-manager-module.js`

Модуль управления другими модулями через графический интерфейс.

Функции:
- Просмотр списка всех доступных модулей
- Включение/отключение модулей кнопками
- "Удаление" модулей (с подтверждением)
- Отображение статуса каждого модуля

Как отключить: Закомментировать строку подключения в `index.html`:
```html
<!-- <script src="js/modules/module-manager-module.js"></script> -->
```

**Важно:** При отключении этого модуля управление другими модулями будет возможно только программно через API.

## Управление модулями

### Включение/отключение модулей программно

```javascript
// Отключить модуль перетаскивания
ModuleSystem.disableModule('DragDropModule');

// Включить модуль перетаскивания
ModuleSystem.enableModule('DragDropModule');

// Проверить состояние модулей
console.log(ModuleSystem.moduleConfig);
```

### Управление модулями через интерфейс

1. В нижней левой части экрана находится панель "🔧 Управление модулями"
2. Для каждого модуля отображается:
   - ✅ Зеленый индикатор - модуль активен
   - 🔴 Красный индикатор - модуль отключен
   - Кнопки управления: "Вкл", "Выкл", "Удалить"
3. ObjectModule нельзя отключить или удалить - он обязательный
4. При отключении/удалении требуется подтверждение
5. При удалении требуется двойное подтверждение

### Конфигурация при инициализации

В файле `js/app.js` можно изменить конфигурацию модулей:

```javascript
const ModuleSystem = {
  moduleConfig: {
    'ObjectModule': true,          // Обязательный модуль
    'DragDropModule': true,        // Перетаскивание
    'ConnectionModule': true,      // Соединения
    'ExportImportModule': true,    // Экспорт/Импорт
    'UIModule': true               // Пользовательский интерфейс
  }
};
```

## Использование

### Запуск приложения

1. Откройте файл `index.html` в любом современном браузере
2. Или используйте локальный сервер:
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Node.js (если установлен http-server)
   npx http-server
   ```

### Добавление объектов

1. Нажмите кнопку с нужным типом объекта в левой панели
2. Объект появится на рабочей области
3. Перетащите объект в нужное место

### Создание соединений

1. Дважды кликните по исходному объекту
2. Кликните по целевому объекту
3. Между объектами появится стрелка

### Редактирование объектов

1. Кликните по объекту для выделения
2. В правой панели измените свойства:
   - Тип объекта
   - Текст содержимого
   - Цвет фона
   - Размеры

### Сохранение и загрузка

1. Нажмите "Сохранить" для сохранения в localStorage
2. Нажмите "Загрузить" для импорта из JSON файла
3. Нажмите "Изображение" для экспорта в PNG

## API для разработчиков

### Работа с объектами

```javascript
// Создать объект
const obj = ObjectModule.createObject('Задача', 'Моя задача', 100, 100);

// Добавить объект на карту
app.addObject(obj);

// Найти объект по координатам
const foundObj = app.findObjectAt(150, 150);

// Удалить объект
app.objects = app.objects.filter(o => o.id !== obj.id);
app.render();
```

### Работа с соединениями

```javascript
// Создать соединение
ConnectionModule.createConnection(obj1.id, obj2.id);

// Удалить соединение
ConnectionModule.removeConnection(connectionId);

// Очистить все соединения
ConnectionModule.clearAll();
```

### Экспорт/Импорт

```javascript
// Экспорт проекта
const jsonData = ExportImportModule.exportProject();

// Импорт проекта
ExportImportModule.importProject(jsonString);

// Скачать проект
ExportImportModule.downloadProject('my-project.json');

// Автосохранение каждые 5 минут
ExportImportModule.enableAutoSave(5);
```

## Примеры использования

### Создание простой дорожной карты проекта

1. Добавьте объект типа "Заголовок" с названием проекта
2. Добавьте объекты типа "Тема" для каждого этапа
3. Для каждой темы добавьте объекты типа "Задача"
4. Отметьте ключевые точки объектами типа "Веха"
5. Создайте соединения между зависимыми задачами
6. Сохраните проект

### Мозговой штурм

1. Быстро добавляйте объекты типа "Заметка" для идей
2. Группируйте связанные идеи в "Темы"
3. Перетаскивайте заметки для организации
4. Экспортируйте результат в изображение
